# วิชาไมโครคอนโทรลเลอร์ (ปวช.)

สื่อการสอนแบบเว็บ (static site) สำหรับ GitHub Pages: สไลด์ แบบฝึกหัด แบบทดสอบ และหน้าเฉลยสำหรับครู

- `index.html` หน้าแรก
- `chNN/slides.html` สไลด์ (← → / Space, T = สารบัญ, F = เต็มจอ)
- `chNN/exercises.html` แบบฝึกหัด (ตรวจทันที, พิมพ์ใบงาน A4)
- `chNN/quiz.html` แบบทดสอบ 20 ข้อ ก่อน/หลังเรียน
- `chNN/answers.html` เฉลยสำหรับครู (ต้องใส่รหัสครู)

บทที่มีแล้ว: `ch01` ความรู้เบื้องต้นเกี่ยวกับไมโครคอนโทรลเลอร์ · `ch02` การเขียนโปรแกรมภาษาซีสำหรับไมโครคอนโทรลเลอร์ (5 ชั่วโมง)

ไฟล์ส่วนกลางใน `assets/`: `deck.js/css` สไลด์ · `sims.js/css` ตัวจับเวลา โหวต กระดานคะแนน สุ่มเลขที่ วิดีโอ · `code.js/css` กล่องโค้ดภาษาซีและผังงาน

## แก้เฉลย / เปลี่ยนรหัสครู
1. แก้ `_private/answers-chNN.json` (โจทย์ตัวเลข `num` ต้องมี `calc` ให้สคริปต์คำนวณซ้ำ)
2. รัน `node _private/encrypt-answers.mjs chNN "รหัสใหม่"` (ต้องมี Node.js 18 ขึ้นไป)
3. อัปโหลดไฟล์ `chNN/answers.enc.js` และ `chNN/check-data.js` ใหม่

โฟลเดอร์ `_private/` อยู่ใน `.gitignore` — ห้ามอัปขึ้น GitHub
